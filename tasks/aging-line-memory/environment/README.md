# Thermal line spectroscopy of a frozen glass

A specimen has N localized basins. Its binding depths E_i are independent positive exponential variables of mean T_g in [0.9,1.1]. Each basin has a permanent distinct spectral line and a fixed magnetic moment m_i of +1 or −1, equally likely and independent of its depth and other basins. Set Boltzmann's constant and the microscopic attempt time to one. A fresh-basin calibration asks whether E_i exceeds the given `threshold` in [0.2,2]. Its reported value is the probability, rounded to eight decimal places.

In one launch, several dilute probe particles are loaded one at a time in the **same** specimen. For each particle equilibrate at the designated setting [T,h], a positive temperature and a signed field in energy units. The energy of basin i is −E_i−h m_i. All basins have equal internal degeneracy. Draw one occupied basin from the Gibbs probabilities of this specimen and record its line. Before the next particle, remove the previous one and restore the specimen. The draw of a fresh particle is independent given the same depths and moments. Line detection changes neither. The last loaded particle remains for an additional exposure.

`settings` lists two settings with temperatures in [0.47,0.74] and fields in [−0.45,0.45]. Each integer in `preparations` is 0 or 1 and selects a setting for the next particle. Both settings occur. There are three or four particles. The optional `tag` is 0 for no magnetic selection, or ±1 to retain only launches in which the first recorded line has this moment. Each entry [a,b,same] of `gate` compares two different earlier readings, excluding the last. Retain the launch if their site labels agree when same is true, or differ when it is false. Apply every listed comparison. An empty gate accepts all.

Immediately after the final equilibrium draw switch off the field, set the temperature to T_g, and expose the last line for d N with `exposure`=d in [0,2.6]. The occupied basin is unchanged at the switch. Its first escape has constant rate exp(−E_i/T_g) in these microscopic units. Reject the launch upon any escape. All the preceding readings came from separate equilibrium preparations and have no survival requirement.

Report the probability that the final line equals the earlier line numbered `mark`, conditional on passing all the selections. Indices start at zero. Each specimen drawn from the disorder law supplies one launch. Pool the accepted launches across specimens, then take N to infinity. In particular a specimen that rarely passes the selections contributes fewer accepted launches. Every graded geometry has limiting selection probability above 0.01.

For a check, take a glass with T_g=1, both settings [0.5,0], preparations=[0,1,1], tag=0, exposure=0, and mark=0. With gate=[[0,1,true]] the reported probability is 0.75. With gate=[[0,1,false]] it is 0.25. In this example half of the launches pass each gate. The public starter computes this zero-field, equal-temperature line law. For a general input it replaces the preparation temperatures by their mean and treats the field, tag and exposure as independent of the recorded lines.

Implement `Model` in /app/model.py. Its `fit(records)` receives input/value dictionaries, sets `depth_scale` to the fitted T_g, and returns self. Its `predict(inputs)` returns a finite one-dimensional real NumPy array in input order, including an empty array for an empty list. Calibration has absolute tolerance 0.00001. Each new reading has absolute tolerance 0.004.
