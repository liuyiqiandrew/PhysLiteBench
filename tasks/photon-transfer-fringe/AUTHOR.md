# Coherent optical return through a finite spin memory

The thermal calibration fixes V=0.8436. Two Fock photons scatter twice from the same chiral Λ atom. Between passes a mode-selective, finite-cell optical store acts on the radiation. A retained event may carry two excitations in the memory with the atom in its ground doublet, or one excitation in the memory with the atom still excited. These alternatives can lead to the same final two-photon outcome. The optical phase acquired per stored excitation controls their interference. The spin-wave write/read phases and single occupancy of each cell also affect the amplitudes. The continuous-field scattering law follows the Fock-state input–output framework of [Baragiola et al.](https://doi.org/10.1103/PhysRevA.86.013811). Collective coupling to a quantized optical mode is treated in the [Tavis–Cummings model](https://doi.org/10.1103/PhysRev.170.379).

## Independent calculations

`single_pass.py` provides the waveguide Fock transfer publicly. It contracts the propagator between unnormalized coherent input/output test states and keeps one field variable per labelled photon. The square-free coefficient with all variables present is the requested matrix on the three atomic levels. Piecewise-constant envelopes give a matrix exponential per interval.

The oracle contracts this transfer with the two-mode Fock basis at each boundary. An occupation (n₀,n₁) has normalization √(n₀!n₁!). An occupied memory spin pattern acquires its site-dependent write phase. With those phases removed, its write amplitude is the symmetric Dicke amplitude divided by the square root of the number of equivalent patterns. In a fixed total-color sector (n₀,n₁), increasing a spin occupation b_c by one couples with magnitude θ_c √[(n_c−b_c)(b_c+1)(M−b₀−b₁)]. The read is the reverse optical transfer with its own pulse areas and site phases. The oracle coherently sums compatible site patterns through the per-cell RF rotations. During the vacuum gap only the no-emission amplitude contributes to two-photon return. A recorded gap emission would leave at most one final photon. The atomic pulse and phase accrue on the same joint amplitude as the memory transfer.

The private reference independently sums all time-ordered emission and absorption histories in each waveguide passage, including direct field contractions and initial or final atomic excitation. Between passes it exponentiates the microscopic light–spin Hamiltonian on individually labelled sites and optical occupations. No Dicke reduction, analytic spin-wave form factor, or coherent-field scattering routine is shared with the oracle. It supplies all frozen labels. The validator compares both calculations on every held-out shot, checks the two analytical square-pulse results, and tests dark one-excitation and bright two-excitation return at π wavevector mismatch.

For the full worked example let B=2(1−exp(−1/2)) and S=1−2(1−B). A constant resonant bright photon has ground-to-ground amplitude S and final excitation amplitude −B. Initial atomic excitation radiates into the received square mode with amplitude B. The spectator passes the emitter directly. The single collective write or read amplitude is w₁=−i, and the two-excitation amplitude for either pulse is w₂=√2[cos(π√3/2)−1]/3. The detected optical amplitude is S²w₂² exp(2iφ)−B²w₁² exp(iφ), where φ is the memory phase. Its squared modulus gives the two public readings divided by V. At the π mismatch of the separate memory check, either individual polarization-0 excitation cancels between the two cell positions. A stored pair occupies both positions, so the two-excitation spatial factor is unity.

## Controls

The public starter uses exact single-pass waveguide transfers, assumes a ground-state handoff and treats each photon as an independently stored spin wave. The stronger negative control uses the full finite memory and both atomic sectors, but measures the number of stored excitations before retrieval and discards the result. Its predictions agree when ground handoff is required and lose observable interference when the handoff is unmeasured. A separate dilute-ensemble comparison retains coherent sectors while multiplying independent one-photon Rabi amplitudes. The 27 held-out geometries differ from the analytical checks.
