# Coherent dual-sector line lock

A size-N Gaussian tree has floor(exp(N ratio*v_F)) families and floor(exp(N ratio*v_L)) actual sites per family. Each site has two basis states b=0,1. A family energy X has variance N gain² v_F. Each basis state has its own increment Y_b of variance N gain² v_L. All energies are centered independent Gaussians except for each family's shared X. Set a=gain*sqrt(2 ratio), c=sqrt(2 ratio)/gain, x=(X+Na v_F)/sqrt(N), and y_b=(Y_b+Na v_L)/sqrt(N).

In each setting the Hamiltonian is a direct sum over sites. The two diagonal energies of a site are X+Y_b−fields[0]*x−fields[1]*y_b+offsets[b]. Its real off-diagonal element is `coupling`, identical for every site in that setting. Each of the two `settings` objects gives `fields`, `offsets` (two numbers each), `coupling`, `window`, `angle`, and `phase` (one number each). Prepare the canonical state at inverse temperature c+window/sqrt(N), independently for both settings on the same sample. Centering and temperatures use the actual gain.

For `sector_lock` measure the site and test cos(angle)|0>+exp(i phase)sin(angle)|1> in each preparation. Require both probes to pass at the same actual site, its X+Na v_F in `root_window`, and its two unmodified line energies X+Y_b+Na(v_F+v_L) in `line_windows`[b]. If `outside` is an object, prepare another independent state in its `setting` (0 or 1) and measure its site and basis state. Require a different family, basis state equal to its `sector` (0 or 1), and the corresponding y_b in its `band`. Null outside omits that measurement.

Return the limit of N^(3/2)*exp(N ratio*v_L) times the whole event probability averaged over original samples. Define all filters and quantum probabilities at finite N. Inputs are the named fields, `observable` and `variances`=[v_F,v_L]. Variances are in [.5,1.24], ratio in [.32,.75], fields, offsets, coupling and windows in [−1.05,1.05], and angle and phase in [−3.18,3.18]. Interval endpoints are increasing in [−1.55,1.55].

For `warm_energy` use just observable, variances, ratio and inverse_temperature in [.08,.34]. Keep only basis state 0 with no offsets, coupling or fields. Return the limiting mean X+Y_0 per N. Fit gain in [.69,1.31]. Calibration rows have input, value and positive sigma. Implement `Model.fit(records)` storing `self.gain` and returning self, and `Model.predict(experiments)` returning one-dimensional NumPy predictions in input order including empty input.
