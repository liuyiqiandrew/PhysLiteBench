# Wall contact and two-dye passage

Each exposure draws a new simple path from 0 to infinity in the upper half-plane. The positive real axis borders its right component. Both dyes and all passive contact probes observe that one path. A wall probe at real x fires if the path intersects the straight vertical segment from x to x + i√(2a). The recorded probability is conditional on **every** listed probe firing, in the limit as their positive capacities a tend to zero. Equivalently, take the coefficient of the product of the capacities in the probability of all contacts and the relevant dye event, separately for the numerator and denominator. A probe does not repel the path.

The model is chordal SLE(8/3), with half-plane Loewner equation ∂t g(z)=2/(g(z)−√(8/3) B(t)) and g at time zero the identity. For a compact boundary-attached hull away from zero, let f map its complement in the upper half-plane back to the upper half-plane, fixing zero and infinity with unit derivative at infinity. The probability of avoiding the hull is f′(0)^(5/8). Conditional on avoidance, applying f to the entire path restores its original law. Interior dye coordinates are carried by the same map.

For one dye z the probability of right membership is L(z)=(1+Re(z)/|z|)/2. For two dyes the ungated probability of both on the right is L(z)L(w) + Im(z)Im(w) G(s)/(4|z||w|), where s=|z−w|²/|z−conj(w)|². The angular function solves 3s(1−s)G′=(s−1)+(s+1)G, with G(0)=1 and G(1)=0. The two-point law is provided so the task can be solved offline.

Each input has two distinct dye positions in pixels, e.g. `"dyes": [[-0.42,0.84],[0.94,0.66]]`. A pair [X,Y] represents the physical point X + i λY in horizontal pixel units. The common unknown λ is in [0.78,1.22]. The `walls` list holds zero, one or two distinct real wall coordinates, already in horizontal units. Each is nonzero. All physical dye heights are positive. The `gate` is `right` or `left` for the required first-dye side. Calibration uses `off` with no probes, so the first dye imposes no condition. The output always concerns right membership of the second dye.

For the example dye positions above and λ=1, with the first dye gated left, the predicted right fraction is 0.881808 without probes, 0.218057 with the probe at 1.34, and 0.281421 with probes at −0.74 and 1.34.

Implement `fit(rows)` to set `self.aspect` and return self. Calibration rows in data/calibration.json contain an `input` and a dimensionless probability `value`, rounded to nine decimals. `predict(inputs)` returns a finite numeric NumPy vector of length len(inputs), in input order, including length zero. The starter performs a single-dye calibration. Replace its gated response with the joint physical reading. The maximum absolute error must be below 0.00002 on calibration and 0.004 on each held-out one-probe, same-side two-probe and opposite-side two-probe set.
