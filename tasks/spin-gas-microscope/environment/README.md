# Two-atom Raman interferometer

An open chain has L sites numbered from 0, with at most one boson per site, and two internal states 0 and 1. Use hopping energy, lattice spacing and ℏ equal to one. In a sector of N atoms, a basis state is specified by increasing positions x₁<…<x_N and a list of internal states s₁,…,s_N read **from left to right**. Hopping to a vacant neighbor has matrix element −1 and preserves this order. The charge density matrix is grand canonical at inverse temperature β and chemical potential μ for this open nearest-neighbor chain. In the ordered position basis it equals the spinless fermion density matrix with that same ordering on both sides.

The initial spin density matrix is diagonal in the ordered list. Its probability is the stationary Markov-chain law with P(1|0)=a, P(0|1)=b, where `flip=[a,b]`. The first spin has P(1)=a/(a+b). Each ordered spin list has the same charge density matrix. Equivalently, the full state has matrix elements ρ_charge(x,y) times the spin-list probability when the two ordered spin lists are identical, and zero otherwise. The charge weights already include number fluctuations.

The two beams act simultaneously on distinct sites. `moves=[[i,j],[k,l]]` specifies one transfer i→j and one k→l; their source sites must be occupied and their destinations vacant. Both annihilated atoms are created at their specified destinations. The two respective `rotations` act on the internal states carried by those atoms. Each other occupied site strictly between the middle two of the four addresses receives the `plate` rotation. All other spins are preserved. The reference arm acts as the identity. In position and spin basis, this defines a transfer operator O, with unit bosonic hopping matrix element for each allowed transferred atom. Each spin rotation acts once in the transfer arm. All atoms are indistinguishable.

A pulse [θ,φ,δ] first rotates through θ about the equatorial Bloch axis (cos φ,sin φ,0) and then rotates through δ about +z. The Pauli-z eigenvalues for states 0 and 1 are +1 and −1. All angles, including the interferometer `phase`, are radians. Let C be Tr(ρ O) for the same moves and charge state with all atoms spin 0 and all pulses disabled. It is positive in the operating window. Return V Re[exp(i phase) Tr(ρ O)/C]. V in [0.7,0.95] is the unknown visibility. Blank records turn both arms into identity and read V cos(phase).

Records use L = `length` in [8,20], β = `beta` in [0.8,2.2], μ = `mu` in [−0.8,0.8], 0.06≤a,b≤0.95, and four distinct site addresses spanning at most ten consecutive sites. A set includes disjoint, nested and interlaced transfers. All pulse angles have magnitude at most π. The helpers in gas.py provide the positive charge coherence for every common spectator occupation in the addressed interval. Each tuple gives the sorted initial positions, sorted final positions, and that charge coherence, summed over exterior positions. They also supply the pulse matrices and associated destinations.

With four consecutive addresses 1,2,3,4, all pulses disabled and phase zero, transfers 3→1 and 4→2 give signal/V=1. Transfers 4→1 and 3→2 give 1−2ab/(a+b). For a nontrivial example, use L=10, β=1.4, μ=0.2, [a,b]=[0.15,0.22], moves [[5,1],[6,3]], rotations [[0.8,−0.3,1.1],[−1.1,0.9,−0.7]], plate [0.65,0.4,0.3], and phase 0.3. The expected signal/V is 0.51850916.

Implement `Model().fit(records)` to store `self.visibility` and return self. Each calibration record in data/calibration.json has an `input` and a real `value` rounded to nine decimals. `predict(inputs)` returns a finite numeric NumPy vector in input order, including an empty vector for an empty input list. Maximum absolute voltage error must be below 0.000002 on calibration and 0.004 in each held-out group.
