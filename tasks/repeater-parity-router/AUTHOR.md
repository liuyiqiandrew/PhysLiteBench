# Parity-heralded Bell-pair routing

Station readout observes the parity of the total number of local memory qubits. It can hide multiple elementary pairs and correlates the link inventories. A narrowband path and a flexible path can both exist on a loading but still compete for a single entangled pair. A shared optical phase also correlates different stored pairs from the same link.

For delivery and contention the positive solver propagates the set of attainable red and blue path-flow parities over the live stations while summing over the actual herald records. An edge may be used by neither route, by either admissible route or by both if two compatible copies exist. Requiring odd path-flow parity at the two endpoints and even elsewhere is equivalent to path existence: a feasible flow contains a simple endpoint path after cycles are removed. The physical station parity constraint applies independently to all generated pairs. For contention the second calculation permits the same elementary pair to serve each request in isolation.

The fringe solver keeps the feasible ordered path pairs for each resource pattern. Within each accepted shot it averages the phase product over those options before averaging over shots. Two distinct memories from a shared link carry the same binary phase. The independent reference directly sums the discrete raw-parity and inventory distributions, constructs simple paths by degree and connectivity, mixes the link-sign states, and averages the two measured XX values. The reference truncates each individual Poisson count at 21, with an omitted tail below 10⁻¹⁷ over the fixtures.

The independent-loading starter misses the resource competition and common phase. A stronger negative control performs exact same-loading routing but gives successive emissions on a shared link independent phases. It passes the delivery and contention groups and fails the fringe group. The validator also checks the effect of weighting a loading by the number of feasible route pairs. Regenerate the frozen data with `python scripts/validate_repeater_parity_router.py --generate`.
