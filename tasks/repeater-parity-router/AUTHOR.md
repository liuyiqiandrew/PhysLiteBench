# Photon-count-conditioned Bell-pair routing

The elementary source phase remains fixed throughout its shot. A separate pilot mode resolves the binary phase at each emission and the collection optics combine counting ports from several links. The detector reports a total photon count without a link label. This count depends jointly on source occupation and phase. It changes the distribution of routable inventories as well as the remote phase fringe.

The positive calculation marks each link inventory by its endpoint parity, routing class and pilot count. For a monitored positive link the pilot count is always zero. For a monitored negative link, nonzero pilot counts resolve its exact total Poisson occupation. The two-color composition conditional on that total is binomial. The solver propagates common station parity, accumulated count and possible ordered pairs of simple routes. For the fringe it uses the phase-weighted link distribution on the symmetric difference of the chosen routes, averaging uniformly inside each successful loading.

The independent reference sums assignments of the source signs on the monitored links. The Poisson sum on the negative ports is apportioned among these sources. It then enumerates the joint elementary resource classes, compatible station images and viable path pairs explicitly. Two analytic shots test the shared-link and route-average laws.

The counter-disconnected starter retains the exact two-receiver circuit. A separate stronger control computes the correct pilot-selected inventory and routing probabilities but uses a statistically independent set of optical phases for the remote Bell states. Its two probability groups pass and its conditional fringe fails. A saturating-counter diagnostic records at most one click per negative link and resolving the actual number of pulses distinguishes this different detector.
