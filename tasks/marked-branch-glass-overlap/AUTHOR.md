# Marked branch glass overlap

This original experiment develops equilibrium entropy and thermal replicas from [Princeton's graduate preliminary exams](https://phy.princeton.edu/academics/graduate-program/degree-requirements/preliminary-exams). The field is an order-one bias on a label at each physical branching depth.

The low-temperature hierarchy is a cascade of stable Poisson processes with exponents alpha_j=sqrt(2 s_j/v_j)/(gain beta). At a single layer, multiplying a stable jump by exp(beta field mark) tilts the associated mark law by exp(alpha_j beta field mark). This leaves the mark independent of the scaled jump. The effect of a node's descendant partition function on that node's Gibbs weight supplies the bias of the child's normalized law from PD(alpha_j,0) to PD(alpha_j,−alpha_previous). Combine the nested partition law with one mark constraint per distinct edge and return zero for contradictory requirements. The completed shortcut uses ordinary Boltzmann mark weighting and unconditioned child partitions.

The oracle works with the labeled partition law and mark likelihoods. The independent reference uses a sequential partition process and applies each new requirement to the existing edge. The validator checks field reversal, normalization, the exact two-draw overlap weights, and direct Poisson mark tilting on a large truncated stable process.
