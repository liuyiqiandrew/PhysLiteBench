# Two-root heralded returns

A size-N sample has floor(exp(N ratio*v_F)) families, with floor(exp(N ratio*v_L)) sites per family. The two entries of `variances` give v_F,v_L. A family energy X is an independent centered Gaussian of variance N gain² v_F, reused at its sites. Each site has an independent centered Gaussian increment Y of variance N gain² v_L. Put A=gain sqrt(2*ratio), c=sqrt(2*ratio)/gain, x=(X+N A v_F)/sqrt(N) and y=(Y+N A v_L)/sqrt(N).

Keep only frozen samples with exactly one family whose X+N A v_F lies in each of the two disjoint `root_windows`. Call the selected families tags 0 and 1 in window order. In setting j use inverse temperature c+settings[j].window/sqrt(N). Ordinary sites have energy X+Y−settings[j].fields[0]*x−settings[j].fields[1]*y. In tag k use X+Y−settings[j].tag_fields[k]*y. The apparatus uses the actual gain. Each Gibbs law includes all sites in the retained sample.

For `heralded_return`, make one independent Gibbs draw at each setting. Require the same actual site in the supplied `tag` (0 or 1), with its Y+N A v_L in `site_window`. If `outside` is an object, also make a third independent draw in its setting and require the other tag with y in its band. Null outside omits the third draw. Take the mean over the retained samples, then return the limit of sqrt(N) times that event probability. Form the finite-size conditional probability before taking the limit.

Main inputs have exactly `observable`, `variances`, `ratio`, `root_windows`, `settings`, `tag`, `site_window` and `outside`. Each of the two settings contains `window`, `fields` and `tag_fields`. Outside has keys `setting` (0 or 1) and `band`. Variances are in [.43,1.24], ratio in [.43,1.14], window magnitudes at most 1.1 and field magnitudes at most .83. All interval endpoints are finite in [−2.15,2.15] and increasing. The two root windows are disjoint in ascending order.

For `warm_energy` use only observable, variances, ratio and a positive `inverse_temperature` below c over the gain range. Use no herald and zero fields. Return the limiting Gibbs mean of X+Y per N. Fit gain in [.68,1.33]. Calibration records contain `input`, `value` and positive Gaussian standard deviation `sigma`. Implement `Model.fit(records)` to set `self.gain` and return self, and `Model.predict(experiments)` to return a one-dimensional array in order, including the empty array for no inputs.
