# Spectral hole feedback

A sample of size N has floor(exp(N s_0)) families and floor(exp(N s_1)) sites per family. The arrays `entropies` and `variances` give s and v in family, site order. Each family has an independent centered Gaussian energy X of variance N gain² v_0. Each site has an independent centered Gaussian energy Y of variance N gain² v_1. The baseline site energy is X+Y. The site entropy-to-variance ratio is above the family ratio. Use units with k_B=1.

For `feedback_record`, draw two or three sites in succession at the supplied `inverse_temperature`, which is above both freezing inverse temperatures throughout the fitted gain range. Use the same physical sample. Draw the first site from the baseline Gibbs distribution. After every draw except the last, perform an addressing pulse `edits[i]` with two entries [family shift, site shift]. It subtracts the family shift from the energy of every site in the just observed family, and also subtracts the site shift from the energy of the just observed site. The registered site gets both shifts. A negative shift raises the corresponding energy. Every addressed change persists through all remaining draws, and repeated changes add. Each subsequent draw is a new independent equilibrium draw conditional on the updated sample. It uses the full current Gibbs normalization over all sites.

Each row of `record` is [family label, site label]. Matching family labels require the same actual family. Within the same family, matching site labels require the same actual site. Distinct labels require distinct branches at that depth. Site labels have no shared meaning across families. Each shot begins with unmodified disorder. Return the probability of that exact record, averaged over shots, taking the thermodynamic limit after forming the finite-sample probabilities.

The top-level keys are `observable`, `entropies`, `variances`, `inverse_temperature`, `edits`, and `record`. The magnitude of each of the shift entries is at most .72. For `warm_energy` calibration use only the first four keys, no shifts, and the supplied high temperature. Return the thermodynamic-limit mean baseline energy per N averaged over disorder. The shared gain is in [.67,1.32]. Calibration rows contain `input`, `value`, and positive Gaussian standard deviation `sigma`. Implement `Model.fit(records)` to return self and store `self.gain`. Implement `Model.predict(experiments)` to return a one-dimensional NumPy array in supplied order, including an empty array for empty input.
