# Hard-core ring: alternate revision of the hard-core boson family

This stage changes the boundary constraint and readout of the open-chain coherence candidate. It is an alternate revision of the same hard-core family, not an independently counted family. The coherence package and every evaluation outcome remain separate and unchanged. Root's original ring prototype is preserved verbatim under prototype/; no model evaluations have been launched from this stage at freeze.

The public model is a periodic eight-site hard-core boson Hamiltonian with fixed total particle number, known signed Peierls phase, known nonuniform site potential and a specified initial number state. The only readout is site density. There is no release protocol or off-diagonal detector conversion. The starter solves the complete one-particle unitary problem and sums the occupied columns, using ordinary fermionic closing-bond phase for every particle number. It retains all public inputs: number selects the initial occupied orbitals, while flux, both potential coefficients, hopping and duration enter the exact propagation.

On the open bonds, the one-dimensional hard-core mapping gives the same hopping matrix. Crossing the closing bond carries the factor (-1)^(N-1) in a fixed-N sector. The extra sign arises from the occupation ordering around the ring, not from an additional physical magnetic flux. The physical bosonic boundary condition in the README is periodic in every sector. Thus the ordinary fermion boundary is correct when N is odd and wrong when N is even. Density remains the same local operator in either representation. The correction changes the global sector of the state solver without changing the readout formula.

The private oracle multiplies the closing one-particle bond by this parity factor. The independent reference instead constructs the complete fixed-N bosonic Hamiltonian directly in occupation states, including the physical complex amplitude of every directed ring hop. It evolves the initial Fock state and averages site occupations. It contains no parity-twisted one-particle matrix and makes no Hilbert-space truncation. The Hamiltonian sign convention is exactly that in the public equation: H[j,j+1]=-J*exp(i*flux/8). Both directed hops and their complex conjugates are explicitly included.

The final validator compares 108 public-domain corner controls plus 36 random controls. The largest oracle/reference discrepancy is 9.01e-14. Direct many-body time integration independently checks the reference eigensolver to 1.76e-12. Both controls conserve number and energy, keep all occupations in [0,1], and respect flux periodicity under flux+2*pi. This periodicity is a site gauge transformation, so the number-state initial preparation and density detector are unchanged. Reflection tests transform flux, the two potential coefficients and site labels together, using a reflection that preserves each initial occupied set; error is below 4.78e-15. Complex conjugation gives the checked identity n(t,flux)=n(-t,-flux). No assertion incorrectly assumes flux reversal alone is a symmetry for an asymmetric preparation and potential.

Calibration has 288 independent records: four repeats of each of 72 short-time, N=3 density settings, spanning three fluxes, three site potentials, four durations and two detector sites. The ordinary and parity-aware controls agree exactly on calibration. The instrument sigma=.001 is fixed independently of hopping and response. All constructors start with hopping=None, and the public fit is unfinished. True J=1 lies within [.8,1.2]; calibration/noise seeds are 119211/119217.

At 121 sampled hopping values across the entire interval, matrix-exponential Frechet derivatives for every calibration setting are positive, with minimum .0227193. Forty-one noiseless fits, including both endpoints, recover J to 3.14e-8. Full-interval objective profiles at the two endpoints and midpoint have a unique sampled minimum. These are numerical identifiability checks, not a formal interval proof. The calibration uses nonzero flux and spatial potential controls; it does not rely on turning off those inputs.

The actual fit gives J=1.0000152251 and reduced chi-square1.02422. Oracle hidden errors are below3.53e-5. The source errors for N=2, N=4 and flux-extreme groups are .51303, .29861 and .40116. Long-time N=3 and initial-density anchors pass both models. Every discriminating group includes all eight site densities for each preparation, so its reference RMS is bounded away from zero by number conservation; no small local signal is used as a relative-error denominator.

All256 noise realizations pass calibration, parameter and oracle checks. The worst oracle error is .002966 and the smallest shortcut error is .29807, against the unchanged .04 group relative RMS gate. Forty-one full-range hopping checks give shortcut group error at least .20060. Local pytest gives oracle10/10 and shortcut7passes/3 intended hidden failures in under one second each. The parameter gate is3%, calibration reduced chi-square gate1.5, and agent/verifier limits remain600/60seconds. The neutral instruction explicitly permits replacing any implementation. No parity, mapping or boundary-correction formula appears in the public package.

The unused number argument in the starter's internal Hamiltonian helper was removed before freeze; number remains used in its state preparation. This signature cleanup changed no predictions, calibration records, physical equations or grading. The complete validator and local controls were rerun afterward without regenerating data. Scientific shortcut rejection is not a model evaluation outcome. Later trial review must distinguish a retained wrong boundary sector from an attempted correct sector with a sign, indexing or implementation error.

The operator mapping is part of the framework developed by Lieb, Schultz and Mattis, [Two soluble models of an antiferromagnetic chain](https://doi.org/10.1016/0003-4916(61)90115-4), Annals of Physics16,407–466(1961). The finite-sector sign and predictions here are derived directly from the specified periodic boson Hamiltonian and checked by its independent Fock construction. The open-chain coherence task instead substitutes a fermionic off-diagonal operator for the bosonic momentum detector; this revision keeps the density operator exact and changes the global boundary sector.
