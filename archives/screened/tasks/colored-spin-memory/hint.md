The undriven Ramsey envelope does not generally define a local dephasing generator that remains valid during transverse drives. The classical field retains memory and becomes correlated with the evolving spin. Propagate the joint noise-coordinate/spin distribution, preserving it across drive segments. One deterministic method expands the Gaussian-weighted conditional Bloch vector in normalized Hermite modes: mode n decays at n/tau; multiplication by xi couples neighboring modes with coefficients noise_width*sqrt(n) and noise_width*sqrt(n+1). The ensemble Bloch vector is mode zero.
