# Hall laminate, revision 1

The completed shortcut computes each phase's correct Drude tensor and arithmetic-averages the tensors before imposing zero average transverse current. It is a mathematically valid common-field approximation and matches every pure-phase calibration exactly. A laminate does not generally have one common electric field: normal current and tangential field are continuous across interfaces.

In layer coordinates, write A=<1/sigma_nn>, B=<sigma_nt/sigma_nn>, C=<sigma_tn/sigma_nn>, and D=<sigma_tt−sigma_tn*sigma_nt/sigma_nn>. Eliminating the phase normal fields gives sigma_eff=[[1/A,B/A],[C/A,D+C*B/A]]. Rotate this tensor into the laboratory basis and impose the specified average current. The oracle uses this exact homogenization. The independent reference instead solves four laboratory-frame equations for both phase electric fields: two imposed average-current equations and the two interface conditions. It does not use a homogenized tensor formula.

Calibration identifies mobility from the pure-phase longitudinal response at varied B. Hidden mixed fractions and oblique orientations test spatial electric-current closure, distinct from multiple carrier species sharing one homogeneous volume. The transverse readout is a signed laboratory component, including any even-field geometric contribution; it is not silently antisymmetrized. Numerical tests cover both observables, interface continuity, average-current conservation, positive local Joule heating, zero-field series/parallel limits and normal reversal.

Hidden RMS errors are normalized by RMS reference resistivity, limit .04. Validate 256 independent noise fits plus parameter extrema.
