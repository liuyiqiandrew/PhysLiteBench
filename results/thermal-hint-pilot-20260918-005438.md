# Thermal hint pilot

This exploratory pilot compares the unchanged instruction, a generic correctness reminder, and task-specific physics guidance on the thermal-piston task. It contains 14 newly executed trials and the previously completed unhinted baseline: five observations per condition.

## Results

| Condition | Full passes | Calibration passes | Corrected physical model | Independent physical check | Median agent time |
|---|---:|---:|---:|---:|---:|
| Baseline | 0/5 | 5/5 | 0/5 | 0/5 | 98.1 s |
| Generic review | 1/5 | 5/5 | 1/5 | 1/5 | 193.7 s |
| Physics guidance | 5/5 | 5/5 | 5/5 | 0/5 | 154.5 s |

The four new baseline trials passed 0/4. The earlier baseline was already known to fail before the protocol was frozen. Infrastructure exceptions: 0.

A full pass requires all public and private tests. Hidden prediction NRMSE must be below 5% in each of three cases. It is normalized by the reference trajectory's departure from the 293 K bath, not by absolute temperature. Calibration requires reduced chi-square below 1.5, and relative conductance error must be below 5%.

## What changed

All 15 submissions passed calibration and parameter recovery. The six passing submissions implemented the correct first-law solution; the nine failures retained the constant-pressure shortcut. Across the three hidden cases, failed predictions had NRMSE of 13.25–27.20%, while passing predictions had NRMSE of approximately 0.035–0.065%, against the 5% threshold. The final failures are physical-model errors; recovered intermediate command or numerical mistakes are documented in the trial notes.

Generic review increased checking activity in these samples, but all four generic failures tested synthetic data generated by their own incorrect predictor. The passing generic trial instead checked its corrected solution against separately expressed reduced energy-balance equations at a new preparation. The physics-guided trials all submitted correct equations, although none executed a separate dynamics residual or independent solver check; one printed predictions for new preparations.

Generic trial 5 is particularly informative: it recognized the physical issue and coded a correct candidate, found that both candidates fit calibration equally well, then submitted the original shortcut. Its failure therefore cannot be described simply as never finding the relevant physics. The trajectory shows a gap between recognizing the correction and including it in the final submission; this pilot does not isolate why that choice occurred.

The observed pass counts favor the task-specific hint in this pilot. Five runs per condition on a development-selected task are insufficient to establish a general advantage across models or physical systems.

## Fixed protocol

All trials used `gpt-5.6-luna` with high reasoning effort, Harbor 0.21.0, Codex CLI 0.154.0, a 600-second agent limit, and a 60-second verifier limit. Four blocks contained one new trial from each condition; the fifth contained both hint conditions. Up to three separate one-trial jobs ran concurrently, with start order shuffled within blocks using schedule seed 20260918. This seed controls scheduling, not model sampling.

The common instruction was:

> Complete `model.py` using the apparatus documentation and calibration measurements in `README.md`.

Added text was fixed before any of the 14 new trials:

| Condition | Added text |
|---|---|
| Baseline | None |
| Generic review | Check your implementation carefully and test its correctness before finishing. |
| Physics guidance | Apply the first law to each gas, including piston work. Distinguish equal pressures between chambers from pressure remaining constant over time. |

Only `instruction.md` differed between conditions. Frozen task hashes and native model/effort metadata were checked for every trial. The data, public environment, private graders, reference solution, and resource limits were unchanged. The solving agent received only the public environment and its condition's instruction through Harbor. All scheduled trials were retained; no outcome-dependent reruns were made.

## Review method

Each classification uses final source, public messages and executed commands, and verifier metrics. A corrected model uses Cv for the temperature sum, Cp for the difference, and the changing-pressure contribution. An outside-calibration test executes a preparation beyond the supplied calibration set. An independent physical check additionally compares behavior with a separately expressed physical constraint or independent solver; generating and refitting synthetic data with the same predictor does not qualify. Equation residual checks and independent trajectory comparisons are distinguished in the per-trial notes.

## Scope and limitations

This is a small pilot on one task, one fixed calibration dataset, and one model setting. The task and model were selected after prior failures, and one known baseline result is included. The hint conditions differ in both content and length. The physics hint supplies the critical pressure distinction, so the comparison measures the benefit of explicit task-specific guidance; it does not establish transfer of a general reasoning strategy. Repeated samples of this task are not independent physical systems. The four new baseline observations are reported separately to expose the timing and selection difference.
