Interpretation
Physics hints have the highest observed completed-pass counts for Luna and Terra in this cohort. This is a descriptive result. Luna uses historical controls, and runtime resources changed during the local study. Hint length is not matched. DeepSeek execution errors dominate its results, so its low completion rate does not establish a physics reasoning deficit.

Luna baseline combines 38 historical Codex CLI 0.154.0/concurrency-4 trials with one local CLI 0.160.0 trial. Local hints used up to 3 concurrent trials before the user scheduling amendment and up to 6 sharing 8 Docker CPUs afterward. Task, instruction and grading hashes match, but client version, run date, concurrency and resource policy differ: this is a descriptive historical-control comparison, not an isolated causal hint effect.
User-authorized scheduling amendment after block 131: earlier local observations used one block/up to 3 trials with unrestricted Docker CPU affinity. Later observations run up to 2 blocks/up to 6 trials, with all main containers and network sidecars sharing Docker CPUs 0-7 of 12. No model, effort, task, prompt, grading, agent timeout or verifier timeout changed. Resource contention can affect completion and cost, so retain execution-cohort labels.
Imported published aggregates, source metadata and hashes were checked locally. Raw remote transcripts were not independently verified locally.

Cost and frontier rules
Costs are API-equivalent estimates for Codex usage and reconciled provider estimates for Prime, not Codex subscription charges. A setting enters its prompt-condition frontier only when all 39 costs are available. There are four eligible settings; five are withheld. Singleton frontiers are shown as points. These are observed frontiers restricted to complete-cost settings, not proven frontiers over the missing settings. Seven Prime observations retain nonzero uncertainty bounds. Upper reserves are not confirmed spending.
