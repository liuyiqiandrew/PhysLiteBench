# Additional Luna High physics tasks

This evaluation uses three fresh, unhinted GPT-5.6 Luna High attempts on each fixed task revision. A qualifying attempt must finish within both time limits, preserve the public checks, fit calibration, return finite values and miss a specified physical prediction. A reviewer checks the submitted model and replays an intervention at its fitted parameter. A solver or verifier timeout, missing measurement, software defect or numerical convergence problem cannot establish qualification.

The [trial manifest](trials.json) records the exact Git trees, image hashes, trial IDs, durations, metrics and fixed-parameter diagnostics.

### Dimer defect window

All three submissions fit the bond activity to 0.9369999994. They reproduced the closed-contour readings and changed the boundary distance weights so the model matched the four-corner example. Two used equivalent inverse-square weights with a rescaled vertical activity. The third used inverse distance. On a six-port, 4 × 3 plate, direct enumeration of four coverings gives a conditional cycle probability of 2809/8211, or 0.342102. The three predictions were 0.286617, 0.426559 and 0.286617. Replacing just the plate-pairing weights while keeping each submission's fitted activity and cycle/gate code reduced all hidden errors below 7.0 × 10⁻¹⁰. The tolerance is 0.004.

The completed control goes further than the public starter. It uses the exact probability of every individual port connection and multiplies those marginals. It still misses the three boundary families by 0.208, 0.284 and 0.255. The oracle and independently reconstructed connection probabilities agreed within 8.2 × 10⁻⁹ on 121 feasible plate assignments in a parameter sweep. Literal positive tiling counts also checked 42 of these distributions. The two-plate enumeration gave the same six-port witness.

A separate corner-port test found that the independent reconstruction could lose precision on extremely rare but feasible assignments. Its original estimate for a 22 × 12 witness was 0.485646. Scaling the linear equations by the preparation weights gave 0.492198, in agreement with the oracle. Only the independent fixture validator, its numerical reference and the author note changed. The Luna inputs, grader, stored predictions and reference solution are byte-identical to the trial revision.

### Terrace winding camera

Two reflected steps can touch through either side of a cylindrical terrace. A zero recorder reading means that side was never touched. A positive recorder reading selects a density at the stated local time. The two histories share the same pair of paths and the same tagged observation.

All three submissions fit γ = 0.927. One used a half-line result when exactly one recorder read zero. Correcting the missing positive reading in its formula still gave 0.434161 on a shot whose target was 0.234537. Imposing the no-hit condition at the opposite wall then gave 0.234537. A second submission multiplied independent half-line recorder densities, giving 0.611989 against 0.908129. A third added an empirical factor to a product of recorder densities. Even after correcting the basis for its mixed boundary condition, it predicted 0.637388 on that same preparation. Replacing the factorized densities with the coupled law at the original diffusivity brought all their predictions within 4.9 × 10⁻⁸. The grading tolerance is 0.004.

An independent reflected random walk tracked both boundary impulses and the tagged position. On the worked geometry it gave 0.49224 for the joint density at 160 gap cells, against 0.49221 from the continuum reference. It also distinguished the zero-contact atom (0.03087) from densities reached by approaching zero through positive recorder settings. The completed control uses both exact single-recorder marginals and fails their joint readout.

## Evaluation and reproduction

The native evaluations used Harbor 0.21.0, Codex CLI 0.154.0, model `gpt-5.6-luna`, reasoning effort `high`, web search disabled, no hint, and three independent attempts with no retries. Every revision allows 1,800 seconds for solving and 180 seconds for verification. Agent networking was allowlisted to ChatGPT and OpenAI hosts. Batches shared a local Docker host and some overlapped.

A frozen copy of the committed task was used for each panel. The reference and the completed physical approximation ran in separate fresh containers. For the approximation, only the installed model was replaced. The Docker build used a locally cached runtime matching the published dependency versions. Every file under `/app` at image creation matched the public environment's source hash. All tasks pin NumPy 2.3.3, SciPy 1.16.3 and pytest 8.4.2. Native submissions, trajectories and verifier logs are retained in the local worktree under the job and trial IDs in the manifest.

Run the local physics check from the repository root with `OPENBLAS_NUM_THREADS=1 python scripts/validate_dimer_defect_window.py`. The other four validators use the same naming convention. [Instructions for running a fresh unhinted batch with the recorded CLI settings](../five-luna-high-20261127/README.md#controls-and-provenance).
