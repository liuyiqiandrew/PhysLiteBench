# Hierarchical configurational system

Boltzmann's constant is one. For size N, configurations have labels (a,b), with a=1,...,floor(exp(0.3*N)) and b=1,...,floor(exp(0.7*N)). The label a names a family of configurations; b is a label within that family.

A sample has energies E_ab=X_a+Y_ab. The X_a are independent zero-mean Gaussian random variables of variance 0.7*N*width**2. The Y_ab are independent zero-mean Gaussian variables of variance 0.3*N*width**2, independent also of every X_a. Thus all configurations in family a share its X_a; each pair (a,b) has its own independent Y_ab. These energies are drawn once and held fixed while the sample equilibrates. The positive material scale width is in [0.8,1.2] in the stated energy unit. There are no additional configuration degeneracies or interactions.

At inverse temperature beta, the Gibbs probability of configuration (a,b) in a given sample is exp(-beta*E_ab) divided by the sum over all configurations of that same sample. Beta is in reciprocal energy units.

Calibration measures the equilibrium mean energy divided by N, first averaged over the Gaussian sample distribution and then taken to N tending to infinity. Its input contains beta in [0.2,0.6]. Each record has input/value/sigma fields; value is this limiting mean plus an independent zero-mean Gaussian measurement error of standard deviation sigma, in energy-per-size units. There are 192 independent readings.

For a prediction at beta in [0.2,6], draw replicas independent equilibrium configurations of the SAME fixed sample at that beta; replicas is an integer from 2 through 6. The observable parent_collision is the probability that all replicas have the same a label. The observable state_collision is the probability that all replicas have the same pair (a,b). Compute each probability within a fixed sample, average it over the original Gaussian sample distribution with equal weight per sample, and then take N to infinity. A prediction is this disorder-averaged probability, not a probability for a typical chosen sample or for separately redrawn landscapes. Each experiment contains beta, replicas, and observable.

The observable leaf_partition is another joint event for these same replicas: all replicas have the same a label, and their b labels have exactly the specified partition. Its additional partition field is a list of positive integer block sizes summing to replicas. The consecutive replica indices form the predetermined blocks: [2,2] means replicas 1 and 2 share one b, replicas 3 and 4 share another b, and those two b labels differ. Similarly [3,1] means replicas 1,2,3 share one b and replica 4 has a different b. Different blocks always have distinct b labels. Return the probability of this one labelled event, not the sum over all permutations of replica indices with the same block sizes. The condition that every replica shares one a is part of the event, not a condition on the sampling distribution. Averaging and the infinite-size limit follow exactly the same order as for the other observables.

Implement Model in /app/model.py. A new model has width=None. fit(records) returns self and stores the fitted width. predict_calibration(records,width=None) returns calibration means. predict(experiments,width=None) returns a one-dimensional finite NumPy array in input order. An explicit real width in [0.8,1.2] overrides the fitted value for that call and leaves the stored value unchanged. With the parameter omitted, fit first. Iterables, duplicates, and empty prediction/calibration iterables with an available parameter are supported. The starter includes prediction helpers and an unfinished fit method.
