# Single-file memory, revision 1

This candidate tests a stationary-increment closure for a tagged particle in a Brownian file. Its supplied covariance is mathematically valid, positive, and has the exact one-time variance for the specified preparation. The missing physics is the two-time memory of the initially fixed particle positions, retained through conservation of particle order. It is not a wrong Gaussian normalization, an unfinished fit control, or an unspecified averaging convention.

The apparatus states an infinite file of identical Brownian point particles, reflecting no-passing collisions, fixed initial positions j/rho in every shot, immediate release at the measurement time origin, and independent noise between shots. The same marked particle is observed at both times. The output is the joint limit Cov[X(lambda*t),X(lambda*s)]/sqrt(lambda) as dimensionless lambda grows at fixed positive dimensional times t,s. It is not asserted to be the finite-time tracer covariance. A long equilibration before starting the measurement would define a different preparation.

Write A=sqrt(D/pi)/rho. The physical covariance is A*[sqrt(t+s)-sqrt(abs(t-s))]. The completed source instead supplies A/sqrt(2)*[sqrt(t)+sqrt(s)-sqrt(abs(t-s))], the covariance of fractional Brownian motion with H=1/4 and a coefficient chosen to reproduce every diagonal value A*sqrt(2t). Both kernels are positive Gaussian scaling processes, and both use all input controls. The source assumes stationarity of increments after fitting the exact one-time growth law. No detector-specific branch switches between physical models.

For the microscopic reference, let independent Brownian paths cross and recover the marked particle by its conserved rank in their ordered positions. At the joint long-time scale its displacement is the origin crossing count divided by rho to leading fluctuating order. Each deterministic initial position x contributes a covariance of two correlated threshold indicators; different paths contribute independently. The continuum initial-position sum is rho times the spatial integral, leaving a factor1/rho in the tagged covariance. The reference integrates the bivariate normal CDF's correlation derivative, using correlation=sin(theta), followed by an independent spatial quadrature. The stable exponent is -(a-b)^2/(2*cos(theta)^2)-a*b/(1+sin(theta)). This reference contains no closed tagged-particle covariance formula. It also contains no claim that finite-time tracer covariance equals a finite-lattice crossing covariance exactly.

The preserved prototype independently sums fixed-lattice crossing covariances and simulates Brownian positions at two times with shared noise history, taking the same sorted rank. Those finite-rank Monte Carlo estimates are supplementary consistency checks with reported standard errors; their fluctuations do not demonstrate a monotone finite-time convergence rate. They are not used for grading. The mathematical microscopic mapping and the joint asymptotic limit identify the deterministic verifier.
